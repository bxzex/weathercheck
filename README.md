# Weathercheck

A weather app I made so I could check the forecast without ads in the way.

Live: https://bxzex.github.io/weathercheck/

It shows current conditions where you are and the next five days. Data comes from WeatherAPI.com. Built with React, TypeScript and Tailwind on Vite.

To run it yourself: `npm install`, then `npm run dev`. `npm run deploy` pushes it to GitHub Pages.
